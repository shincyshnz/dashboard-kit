## @dashboard-kit/tokens 0.3.0 — design tokens in DTCG JSON (ADR 0011)

- Token values moved from YAML in `DESIGN.md` to `design-tokens.json` (DTCG: groups, `$value`, inherited `$type`, `$description`, `{aliases}`, `$extensions`)
- Tenant themes are `themes/<name>/design-tokens.json` (overrides only); aliases resolve after merging; old theme notes became `themes/<name>/README.md`
- Values accept readable CSS strings (house style) or DTCG object forms (colour, dimension, duration, shadow, cubicBezier, fontFamily)
- `DESIGN.md` rewritten as the design guide: intent, rules, agent instructions, changelog, and token tables generated by `pnpm tokens:docs`
- Generated JSON Schemas (`packages/tokens/schema/`) give editor autocomplete; validated with ajv
- `pnpm docs:check` now also fails on stale DESIGN.md tables or schemas; watch mode refreshes the tables
- Clearer errors: JSON syntax errors with line/column; validation errors use the JSON paths you edit
- Importer writes into the JSON, keeps `$description`s, normalises values to strings
- 30 tests (was 18); generated CSS/JSON verified byte-identical to the YAML version
- ADR 0002 superseded by ADR 0011; learning note `docs/learning/dtcg-json-tokens.md`

## 0.2.0 — Phase 1 (design token system)

- **Tenant themes:** `themes/<name>/DESIGN.md` with overrides only, scoped by `data-theme`, switchable at runtime; examples `grove` and `ember`
- **Runtime variables for everything themeable:** fonts, spacing unit, text sizes, shadows and easing now switch with the theme
- **New tokens:** `density.spacing`, `fontSizes`, `motion.duration`, `motion.ease`
- **Contrast checks:** WCAG check for all text/surface pairs in every theme and mode, configurable via `checks.contrast`
- **Figma import:** `pnpm tokens:import` for DTCG JSON; comment-preserving, validated with rollback
- **Theme diff:** `pnpm tokens:diff` with semver bump check and `--strict` mode
- **Outputs:** `base.css`, `themes/<name>.css`; `tokens.json` now lists all themes
- **Starter:** theme picker in the header, `forcedTheme` prop for tenant apps, no-flash brand restore, design page shows the active theme incl. density, type scale and motion
- **Harbor 1.1.0:** light `success` darkened to pass AA (was 4.34:1)
- Vitest suite for the tokens package (18 tests); ADR 0005
